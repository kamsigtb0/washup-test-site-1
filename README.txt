WASHHUP WEBSITE DEMO
====================

FILES
- index.html: website content
- styles.css: responsive desktop/mobile styling
- script.js: navigation, booking form, price summary and WhatsApp message
- assets/washhup-logo.jpg: supplied Washhup logo

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a browser, or use VS Code + Live Server.
3. For production, upload the contents to your hosting provider.

IMPORTANT SETUP
- The booking form prepares a WhatsApp message. To send directly to Washhup's official WhatsApp account, open script.js and set waNumber to the business number including country code, digits only (for example 2348012345678).
- The service prices are demo starting prices. Confirm and edit them before publishing.
- Booking submission, user accounts, online payments, service-provider discovery, notifications, and live job tracking need a secure backend and integration. This front-end demo does not claim those are connected.
- Social profile links use the handle washhupng; check that the URLs match the official accounts before publishing.
- Images for the car service cards are loaded from Unsplash and require an internet connection.
- Supplied logo is included as provided. A transparent PNG/SVG version would look sharper on the dark background.

VIDEO ADDED
- The uploaded Washhup promo video is stored at assets/washhup-promo.mp4 and embedded in the page under 'Washhup Tips & Updates'.
